# SQL_Bootcamp

Курс по изучению основ PostgreSQL. На курсе я работала с тремя базами данных: одна для заданий 1-5, 7-11, другая для задания 6, третья для задания 12.

## SQL-1 Basics
В этом проекте я научилась создавать SQL-запросы с использованием внутренних подзапросов в частях FROM и SELECT, а также фильтровать данные по диапазону дат. Я потренировала навыки работы с условиями выборки, сортировкой по нескольким полям с разными направлениями и структурированием запросов для получения нужной информации.

## SQL-2 Retrieving Data
В этом проекте я освоила основные навыки работы с SQL: использование множеств и операторов объединения, создание подзапросов, сортировку по нескольким столбцам, а также разные виды соединений таблиц.

## SQL-3 Retrieving Data Deep Dive
В этом проекте я освоила основные навыки работы с SQL и реляционными базами данных: понимание реляционной алгебры, использование различных типов соединений (JOIN), создание запросов с помощью CTE, обработку пропущенных значений, фильтрацию и сортировку данных.

## SQL-4 DML
В этом проекте я научилась извлекать данные из базы с помощью сложных SQL-запросов и изменять их при помощи языка управления данными (DML) — вставлять, обновлять и удалять записи для поддержания актуальности базы.

## SQL-5 Snapshots
В этом проекте я научилась создавать и использовать представления (views) для фильтрации данных, генерировать временные диапазоны и находить пропущенные даты, работать с операциями над множествами, рассчитывать скидки и управлять материализованными представлениями, включая их обновление и удаление.

## SQL-6 Salesman problem
В этом групповом проекте я научилась применять SQL-инструменты для решения классической задачи коммивояжёра (Traveling Salesman Problem). Я освоила навыки моделирования графов и маршрутов в SQL, научилась создавать таблицы с узлами и стоимостью перемещений, а также писать запросы для поиска оптимальных путей с минимальными затратами и анализа результатов с сортировкой.

## SQL-7 Database index
В этом проекте я освоила продвинутые техники работы с индексами PostgreSQL: я научилась создавать разные типы индексов, анализировать запросы и оптимизировать их.

## SQL-8 Integrating features
В этом проекте  я научилась реализовывать бизнес-требования, обеспечивать целостность данных через ограничения и индексы, оптимизировать производительность БД, работать с последовательностями и массовыми операциями, а также документировать структуру базы.

## SQL-9 OLAP
В этом проекте я освоила ключевые практические навыки SQL-анализа, необходимые для решения реальных бизнес-задач: агрегацию данных (расчет сумм, средних, минимума/максимума), группировку по атрибутам, фильтрацию результатов, соединение таблиц и работу с условиями.

## SQL-10 Isolation levels
В этом проекте я изучила работу транзакций и уровней изоляции в PostgreSQL: воспроизвела классические аномалии данных (Lost Update, Dirty Reads и др.), проанализировала механизм взаимоблокировок (deadlock) и научилась управлять согласованностью данных в параллельных процессах.

## SQL-11 Functions and procs
В этом проекте я освоила создание функций (SQL/PLpgSQL) и триггеров для реализации бизнес-логики на уровне СУБД, научилась разрабатывать систему аудита изменений данных и оптимизировать запросы.

## SQL-12 Warehouse fundamentals
В этом проекте я разобралась, как устроены хранилища данных (DWH), и прошла весь путь создания ETL-процесса. Я писала SQL-запросы, которые умеют обрабатывать «неидеальные» данные: искать пропущенные значения, связывать информацию из разных источников и корректно агрегировать показатели.
